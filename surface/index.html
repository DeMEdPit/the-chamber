Four ways to use it

Read a mindPERCEPTION

The head brain of the canary, 834 bytes, from any node.

cast call 0x6f54E1aAE0E9A679A52e5E733645cB11e0cE6127 'brain(uint256)(bytes)' 1 --rpc-url $RPC

Pull a program out and run it off the chainTHE CHAMBER

Any Chamber token's program, stamped with the block you pulled it at. Save the hex as a file and it is an ordinary C64 program; a browser emulator will boot it.

cast call 0x75FD5A9c4440c38561A0099B216F825b7C6db924 'prg(uint256)(bytes)' 55 --rpc-url $RPC | python3 -c "import sys;open('chamber-55.prg','wb').write(bytes.fromhex(sys.stdin.read().strip()[2:]))"

Train a brain without owning a tokenPERCEPTION

The same replay the contract uses to judge a save, as a free call: hand it any admissible 834-byte parent and any lesson stream, get the child back.

cast call 0x6f54E1aAE0E9A679A52e5E733645cB11e0cE6127 'replay(bytes,bytes)(bytes,uint16)' $PARENT_HEX $LESSONS_HEX --rpc-url $RPC

Pin a revision for everPERCEPTION

Every revision's brain is its own data contract. Read the record, take the blob's address, and read the bytes straight from it - skipping the first byte, which is a STOP.

cast call 0x6f54E1aAE0E9A679A52e5E733645cB11e0cE6127 'revision(uint256,uint32)' 1 3 --rpc-url $RPC   # the first word is the brain blob's address
cast code $BLOB --rpc-url $RPC   # 0x00 then the 834 bytes

Who can change what

Open is a claim about authority before it is a claim about functions. The two contracts answer it differently, and both answers are checkable from the ABI and the chain.

Perception Chamber Canary

No owner, no admin and no upgrade path: the ABI has no function that could add one. The program, the page, the image and the words are four immutable pointers, set at construction and checked against commitments there. One write changes the work's state, saveMind, and only the token's holder may send it; an approved operator cannot, because the holder check is ownerOf itself. The standard's writes move the token and nothing else.

  • the only write outside the ERC-721 standard is saveMind. derived from the ABI by the exporter, which refuses to run if that changes
  • the holder, and no operator or approval. in the verified source, _holderOf is ownerOf; the four pointers and totalSupply are declared immutable

The Chamber

Two writes, both spent. mint could be called by the minter until the lock, once per id, with that id's row of the table; lock could be called once, only after all sixty-four existed, and it set the minter to the zero address. Since then nothing an address can change remains, and the base program, the image and the renderer were immutable from construction.

  • the only writes outside the ERC-721 standard are mint and lock. derived from the ABI by the exporter, which refuses to run if that changes
  • the lock, done. locked() true and minter() the zero address since block 25,929,620, 8 September 2026 · tx 0x10118db3… block 25,929,620

Not exposed

Where the surface stops. Each of these is a decision, recorded, not an oversight.

asking a mind what it would do
the forward pass and argmax are internal to the learner library, inlined into the token; they run on every lesson of every save and are not callable on their own. For now you run the learner yourself. A decision for the 64-token release.
the retina table as a view
the 240-byte vocabulary is a parameter of the interpreter in the code and pinned in the deployed replay; a different world needs a later contract.
who taught
no contract can say. savedBy is the address that committed a save, not who held the joystick.
the contract source on GitHub
the source is public as verified code on Etherscan; a public repository is a parked decision.
